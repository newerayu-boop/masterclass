### Как менять лендинги

- **HTML лендингов не править руками.** Он генерируется из `tools/build_lp.py` (все тексты, кейсы, возражения, порядок блоков). Правка → `python3 tools/build_lp.py` → обновятся `dist/lead/index.html` и `dist/vsl/index.html`.
- Стили: `dist/lp/lp.css` (mobile-first; брейкпоинты 360 / 640 / 760 / 1000 px). Скрипт: `dist/lp/lp.js`.
- После правки CSS/JS поднять версию `?v=N` в `head()` и `TAIL` внутри `build_lp.py`, иначе браузеры покажут старое.
- Видео для /vsl: в `build_lp.py` переменные `VIDEO_SRC` (путь к mp4 в `dist/lp/` или ссылка YouTube) и `REVEAL_AT` (секунда, когда в видео звучит оффер; с неё под видео появляется кнопка). Пока видео нет, показывается постер «Video tez orada».
- Meta Pixel / GA4: в `dist/lp/lp.js` объект `CFG` (`metaPixelId`, `ga4Id`). Пусто = выключено. При заполнении шлются PageView и событие Lead / generate_lead после успешной заявки.

## Жёсткие правила (заказчик на этом обжигался)

- **Никогда не писать тестовые строки в реальную таблицу без явного согласия.** Формы тестировать только с подменой запроса (Playwright `page.route('https://script.google.com/**', ...)`).
- **Не менять Apps Script**, если без этого можно обойтись: заказчику тяжело перевставлять и переразвёртывать его. Новые данные кодировать в существующие поля.
- Не гонять заказчика по исследовательским шагам «проверь то, открой это». Диагностировать самому и давать один чёткий набор действий.
- Не выдумывать факты, цифры, гарантии. Источники фактов: основной сайт `dist/index.html`, honor-keys.vercel.app, слова заказчика.
- Перед выкладкой проверять вёрстку на 320 / 375 / 390 / 414 / 768 / 1024 / 1440 px: без горизонтального скролла, форма на телефоне видна на первом экране.
- Общение с заказчиком: по-русски, коротко, по делу, без воды. Тексты сайтов: по-узбекски.

## Как проверить и опубликовать

```sh
# локальный просмотр
python3 -m http.server 8765 --directory dist
# открыть http://localhost:8765/lead/  и  /vsl/

# пересобрать лендинги после правки текстов
python3 tools/build_lp.py

# опубликовать на GitHub Pages (лендинги /lead и /vsl)
bash tools/publish_pages.sh

# основной сайт на Vercel (из корня, проект привязан к ai-strateg-ten)
npx vercel deploy --prod
```

Git: изменения вливаются в `main` через PR. GitHub Pages публикуется из ветки `gh-pages` (её обновляет `tools/publish_pages.sh`, руками не трогать).
